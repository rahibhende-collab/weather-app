# 🌦️ Weather App

A simple **Weather App built with Python** that fetches and displays weather information using a weather API. The project is developed entirely in Python without using HTML or CSS.

## 🚀 Features

* 🌍 Search weather by city
* 🌡️ Display current temperature
* 💧 Show humidity
* 💨 Display wind speed
* ☁️ Show weather conditions
* 🔄 Fetch real-time weather data using an API
* 🖥️ Simple Python-based user interface

## 🛠️ Technologies Used

* **Python**
* **Requests** – For API requests
* **Tkinter** – For the graphical user interface
* **JSON** – For processing API responses

## ⚙️ Installation

1. Clone the repository:

```bash
git clone https://github.com/your-username/weather-app.git
```

2. Open the project folder:

```bash
cd weather-app
```

3. Install the required library:

```bash
pip install requests
```

4. Add your Weather API key in the Python file.

5. Run the application:

```bash
python weather_app.py
```

## 🔑 API

This project uses a weather API to retrieve real-time weather information.

Replace the API key with your own key before running the application.
