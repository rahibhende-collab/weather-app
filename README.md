# 🌦️ Weather App

A simple **Weather App built with Python** that fetches and displays weather information using a weather API. The project is developed entirely in Python without using HTML or CSS.

## 🚀 Features

* 🌍 Search weather by city
* 🌡️ Display current temperature
* 💧 Show humidity
* 💨 Display wind speed
* ☁️ Show weather conditions
* 🔄 Fetch real-time weather data using an API
* 🖥️ Simple Python-based user interface

## 🛠️ Technologies Used

* **Python**
* **Requests** – For API request
* **Streamlit** - Python library used to create web applications directly from Python code
* ** dotenv** - Python library used to store and load environment variables, especially sensitive information like API keys, passwords, and database credentials.
